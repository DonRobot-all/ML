Интерактивная демонстрация: зачем нужен скрытый слой в нейросети

Задача: научить сеть различать два класса точек

Без скрытого слоя

выход = w₁·x + w₂·y + b
Не справляется

Со скрытым слоем

h₁ = ReLU(w·x + w·y + b)
h₂ = ReLU(w·x + w·y + b)
выход = w·h₁ + w·h₂ + b
Справляется

Граница решения — то, что нейросеть "нарисовала" внутри себя. Одна линия = нет скрытого слоя. Кривая = есть скрытый слой.
